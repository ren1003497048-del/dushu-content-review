# 「独树不成林」内容来源对照

> 中文播客「独树不成林」（主播：仲树）部分单集的文本来源对照 · 随机抽样阶段性核查

## 这是什么

这是一份针对中文播客 **[「独树不成林」](https://www.xiaoyuzhoufm.com/podcast/64acd33c7a3d479103fbd32d)** 部分单集所做的文本来源对照。

该播客以个人视角讨论文学、哲学、政治与历史，在中文播客平台（小宇宙、Apple Podcasts 等）有较大传播。本项目的工作是：把它的若干期节目文字内容，与境外播客、英文专著及公开报道**逐项比对**，并如实刊出对照结果。

## 怎么看

- **在线对照报告**：[index.html](index.html)（自包含单文件，直接打开即可）
- 报告内每条对照均附**原始音频链接**（点开即可自行核验）与转录稿校验和
- 比对结论分若干层级，措辞克制：**高度吻合 / 存在对应·待核实 / 部分吻合 / 来源待定位 / 暂未发现 / 署名完整**

## 范围声明（重要）

- 该播客全档共 **349 期**，本报告目前仅呈现其中 **38 组**比对记录
- 这是**随机抽样阶段性成果，非全量普查，非最终结论**
- 部分对照源自社区已有的讨论线索，部分为本项目在抽样中自行发现
- **未收录的期数不代表已核查或已排除，只代表尚未比对**

## 方法（简述）

1. RSS 全目录建库（该播客 349 期 + 12 家境外播客源库）
2. 跨语言语义初筛出候选对照对
3. 双方音频 → 本地语音转录（SenseVoice）
4. 就叙事顺序、论证结构、具体细节（数字、轶事、比喻、玩笑）逐项比对
5. 由独立语言模型（不参与判级）复核对应强度
6. 语音识别错别字原样保留、不修饰，供第三方复核

## 声明

本项目为文本比对记录的整理，**不构成法律结论，不对当事人作动机推断**。所列均为文本对照事实，是否构成抄袭或洗稿，请读者依据材料自行判断。
